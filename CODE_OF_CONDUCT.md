# Code of Conduct

We want this project to be a friendly, harassment-free place for everyone, regardless of age, experience, identity, language or
background.

**Expected:** be respectful and patient; give and accept constructive feedback; assume good intent; help newcomers; keep
discussion on topic.

**Not acceptable:** harassment, insults, discrimination, personal attacks, doxxing, spam, and asking for or sharing pirated
software.

Maintainers may remove comments, close issues or pull requests and ban people who break these rules. To report a problem,
open a private security advisory on GitHub ("Report a vulnerability") or contact the maintainer through their GitHub profile.

This text is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

---

**Русский:** уважайте друг друга, будьте терпеливы, давайте и принимайте конструктивную критику, помогайте новичкам.
Недопустимы травля, оскорбления, дискриминация, спам, а также просьбы о пиратском ПО и его распространение.
Мейнтейнеры вправе удалять комментарии и закрывать обсуждения.
