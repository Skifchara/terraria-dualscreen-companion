# Terraria Dual Screen Companion

**Приложение-компаньон для Terraria на Android-устройствах с двумя экранами (сделано и проверено на AYN Thor).**
Игра работает на верхнем экране как обычно, а нижний становится живой сенсорной панелью: инвентарь, снаряжение, крафт,
сундуки, баффы, карта и фон, который следует за вашим положением, — всё на основе *настоящего* состояния игры.

[English](README.md) · [Руководство](docs/GUIDE_RU.txt) · [Как помочь](CONTRIBUTING.md) · [Архитектура](docs/ARCHITECTURE.md)

> **Статус:** работает в одиночной игре через [TL Pro](https://play.google.com/store/apps/details?id=com.pixelcurves.terlauncher).
> Проект ранний, но рабочий. Помощь очень приветствуется — см. [CONTRIBUTING](CONTRIBUTING.md) и открытые задачи.

## Возможности

- **Инвентарь**: слоты, монеты, патроны, мусорный слот, сортировка; перетаскивание — переместить, поменять, сложить;
  двойной тап делит стопку.
- **Окно предмета**: крупный спрайт, цвет редкости, характеристики, подсказка игры, проценты от зачарования, кнопки
  (Применить, Надеть, В избранное, Разделить, Выбросить, Удалить, В сундук, Забрать).
- **Жесты у края при перетаскивании**: вверх — выбросить, вниз — применить / надеть / призвать, вправо — в мусор, влево — в избранное.
- **Снаряжение, крафт, сундуки, хранилища и торговля с NPC**, хотбар, здоровье и мана (тап — сердца и звёзды), баффы и дебаффы,
  информационные предметы (часы, глубиномер, компас, метеорадио).
- **Карта**: плавное перемещение, зум щипком, головы городских NPC, значки боссов со здоровьем.
- **Скрыть HUD** убирает родной HUD с верхнего экрана; геймпад управляет компаньоном (L1 / R1 — хотбар, Y — вкладки).
- **Фоны самой игры**: слои вашего биома с параллаксом, стены пещер, тон по времени суток, облака, дождь и снег,
  вспышки молнии, вспышки по краям при уроне / лечении / мане, звуки интерфейса игры.
- Английский и русский.

Всё нарисовано спрайтами, шрифтами и фонами самой игры, декодированными **на вашем ПК из вашей установленной копии**
(см. [Юридическое](#юридическое)). Без распознавания экрана, без выдуманных данных, без виртуальных нажатий: главной остаётся игра.

## Как работает

```
Terraria (верхний экран)  <──  мод TL Pro (JavaScript, src/tlpro)  ──TCP 127.0.0.1:38656──>  приложение (Java, src/companion)
```

Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт

1. Установите Terraria (Google Play) и TL Pro. Сделайте резервную копию сохранений.
2. Установите APK со страницы [Releases](../../releases) (подписан ключом разработки).
3. Импортируйте `Terraduo-Companion-mod-*.tl` в TL Pro и включите пакет. После каждого обновления мода перезапускайте игру через TL Pro.
4. Один раз на ПК подготовьте спрайты (`tools/extract_assets.py`, `tools/extract_backgrounds.py`, см. [руководство](docs/GUIDE_RU.txt), шаг 4).
5. Запустите одиночный мир и откройте **Terraduo Companion** — он сам откроется на нижнем экране.

## Сборка

```
python tools/build.py        # build/terraduo-companion.apk (ключ разработки)
python tools/build_tlpro.py  # build/terraduo-hotbar.tl (пакет мода TL Pro)
```

Нужны JDK (`JAVA_HOME`), Android SDK (`ANDROID_SDK_ROOT`, build-tools и platform `android-33`) и Python 3.10+. См. [BUILD.md](BUILD.md).

## Юридическое

- **В репозитории и в релизах нет ресурсов игры.** Спрайты, шрифты и фоны декодируются локально из установленной вами копии
  Terraria и остаются на ваших устройствах. Не распространяйте их.
- Проект **не** снимает, не обходит и не ослабляет проверку лицензии или защиту и никогда не изменяет и не переподписывает APK игры.
  Не используйте его со взломанными копиями; обращения, связанные с ними, будут закрываться.
- Только одиночная игра. Не для онлайн-серверов.
- Terraria — торговая марка Re-Logic. Проект неофициальный и не связан с Re-Logic и разработчиками TL Pro.
  Несколько скриншотов в `docs/screenshots` показывают графику игры только для иллюстрации.
